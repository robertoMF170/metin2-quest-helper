# MT2Guide - MISSOES DE CACA (avlanma gorevi / missao de caça)
# Fonte: pt-wiki.metin2.gameforge.com  ->  "Missões de Caça" (Lv 2 a 119)
# ============================================================================
# COMO FUNCIONAM (no jogo):
#   - falas com o NPC das missoes de caca e ele da-te DUAS OPCOES;
#   - escolhes UMA (ex: "10x Cao Selvagem Feroz" ou "5x Lobo Feroz");
#   - o jogo passa a contar SO' o mob da opcao que escolheste;
#   - se saires/teleportares antes de escolher, o jogo escolhe uma por ti;
#   - recompensa: EXP + Yang + item aleatorio.
#
# O QUE O GUIA FAZ COM ESTAS MISSOES:
#   - o passo mostra O MOB E A QUANTIDADE DE CADA OPCAO
#     ("ESCOLHE 1 DE 2: [1] mata 10x Cao Selvagem Feroz  ou  [2] mata 5x Lobo Feroz");
#   - o guia DESCOBRE sozinho qual escolheste (pelo mob que travaste/mataste)
#     e, se nao conseguir, tu dizes: botoes  Op.1  /  Op.2;
#   - a MIRA VERMELHA fica em cima do mob que conta e o contador (3/10)
#     sobrevive a sair do jogo (MT2Guide\Saves\<personagem>.txt).
#
# FORMATO DOS PASSOS DE CACA (coluna 8 = extra):
#   cat=caca
#   op1=<quantidade>:<nome do mob da opcao 1>   [:<vnum> se o souberes]
#   op2=<quantidade>:<nome do mob da opcao 2>   [:<vnum> se o souberes]
#   sub=<dica>
#   Os vnums dos mobs "Feroz"/"Mau"/"Elite" nao existem em nenhum ficheiro
#   que o guia consiga ler -> o guia APRENDE-OS em jogo e guarda-os em
#   MT2Guide\Data\mobs_vnum.txt (podes editar esse ficheiro a mao).
#   Escreve sempre o NOME COMPLETO do mob: e' por ele que a mira o encontra.
# ============================================================================
